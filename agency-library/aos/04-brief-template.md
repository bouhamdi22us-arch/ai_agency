# 04 · Brief template — copia este formato para TODA asignación

## TASK ASSIGNMENT

**Project:**        [nombre del proyecto/workstream]
**Assigned to:**    [agente real instalado — verificar con `ls ~/.config/opencode/agents`]
**Department:**     [ING / MKT / DSGN / PRD / SALES / R&I / OPS / EXEC]
**Objective:**      [1 frase, medible; si no se puede medir, la tarea no está lista para delegar]
**Background:**     [qué existe, qué se hizo antes, por qué ahora]
**Audience:**       [quién usará el entregable]
**Responsibilities:** [qué es de este agente; qué NO es]
**Deliverable:**    [archivo/formato exacto, ruta, alcance]
**Acceptance:**     [criteria verificables que decide "listo"]
**Constraints:**    [tiempo, presupuesto, tokens, tech stack, marca, legales]
**Dependencies:**   [qué necesita llegar antes]
**Quality level:**  [CRÍTICA (dinero/prod) / NORMAL / EXPLORATORIA]
**Budget:**         [coste/tiempo máximo aceptable]

## Reglas de envío
- Sin objetivo = devolver el brief. Sin acceptance = no hay gate.
- Si el asignado no puede acometerlo: lo declara, no lo improvisa.
- Un assignment = un deliverable; múltiples asignaciones si hay más.
