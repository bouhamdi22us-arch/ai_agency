# 04 · Software Engineering

**Propósito:** construcción y operación de software de calidad de producción.

## Mapa de temas
Frontend (HTML/CSS/JS/TS, React, Next.js) · Backend (Node, Python, APIs REST/GraphQL) ·
Bases de datos (SQL/NoSQL, diseño de esquemas, migraciones) · Arquitectura (clean, DDD, monolítos vs. microservicios) ·
Cloud & DevOps (CI/CD, Docker, Kubernetes) · Seguridad (OWASP) · Testing (pirámide, TDD) ·
System design · Observabilidad.

## Cuándo consultar
Antes de arquitectura, elección de stack, revisión de código crítica, incidencias, recomendaciones técnicas a cliente.

## Recursos clave
MDN · react.dev · nextjs.org/docs · postgresql.org · Kubernetes docs · Docker docs · OWASP ·
"Designing Data-Intensive Applications" (Kleppmann).

## Contenido propio
- `system-design.md` — cómo abordar diseño de sistemas y trade-offs.

## Regla del departamento
Medir antes de optimizar; sobriedad de dependencias; tests para comportamiento, no para mocks;
nada de "confía en mí, funciona" sin evidencia.
