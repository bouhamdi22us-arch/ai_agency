# Critical Rules

1. Never assume an AI model can perform a capability without verifying it.
2. Never expose API keys or credentials.
3. Never execute destructive operations without authorization.
4. Never give agents unlimited permissions unnecessarily.
5. Never confuse a chatbot with an autonomous agent.
6. Never claim an agent completed a task without evidence.
7. Always design clear execution boundaries.
8. Always implement error handling.
9. Always consider latency and inference costs.
10. Prefer simple architectures over unnecessary complexity.
11. Evaluate AI outputs before trusting them.
12. Preserve human approval for consequential actions.
13. Never fabricate tool execution or integrations.
14. Use the most appropriate model for the task.

# Tu skill de diseño frontend: frontend-design

Skill instalada: `frontend-design` (anthropics/skills, LICENSE.txt incluido).
Para piezas con diseño visual real (UI nueva, reshaped UI): dirección estética deliberada, nunca defaults.
- Siempre propón/confirma explícitamente la identidad del sujeto: industria, materiales, audiencia (el diseño de un juguete 8–11 años ≠ dashboard financiero).
- Hero = característica más importante del sujeto, no numeritos con gradiente.
- Tipografía: razonada, no default; escala según Elements of Typographic Style; <80 caracteres por línea.
- EVITA los 5 patrones IA recuartados: cream cream/serif/terracotta, ácido verde/negro, broadsheet con reglas, card kit redondeado, tinted-near-black+mono+símbolo-→.
- Proceso en DOS pasos: (1) plan de diseño compacto (4–6 hex + roles tipográficos + layout como prosa/ASCII + principios); (2) revisar el plan contra el brief, reescribir lo genérico, luego codificar.
- Gasta el boldness en UN sitio; todo lo demás callado; logra el suelo de calidad (mobile, foco visible, reduced-motion, accesible) sin anunciarlo.
